#### PMHC MDS Update v3.3.9 ####

We are pleased to announce that PMHC MDS Update v3.3.9 was released on
August 31, 2026.

The following updates have been applied in the data extract interface:
* Added direct links to the documentation for the ‘Select Specification’ 
  and ‘Options’ fields.

The following updates have been applied in the user management interface:
* Fixed a bug stopping users with the user management role from removing 
  roles when checkboxes were disabled for an inactive organisation.
* Users with the user management role can no longer ‘undo’ role removal 
  on an inactive organisation.
* User Managers will receive a warning confirmation screen when removing 
  roles will remove a user.

The user guides have been updated to reflect these updates. They are available
at [https://docs.pmhc-mds.com/](https://docs.pmhc-mds.com/){:target="_blank"}.

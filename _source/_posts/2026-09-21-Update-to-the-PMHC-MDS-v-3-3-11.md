#### PMHC MDS Update v3.3.11 ####

We are pleased to announce that PMHC MDS Update v3.3.11 was released on
September 18, 2026.

The following updates have been applied:
* Updates to improve accessibility.

The following updates have been applied in the organisation management interface:
* Improved the confirmation message when deleting a Site to make it clear 
  that any service contacts recorded using the site will also be updated as 
  if no site was provided for the contact.

The following updates have been applied in the reporting interface:
* Added a link to the Reports section of the online user guide.

The following updates have been applied in the naming scanning service:
* Updated the email that is sent when name like keys are found to include a link to the online documentation.

The following updates have been applied in the upload interface:
* Improved the validation of duplicate UA Needs Identifications.

The user guides have been updated to reflect these updates. They are available
at [https://docs.pmhc-mds.com/](https://docs.pmhc-mds.com/){:target="_blank"}.
